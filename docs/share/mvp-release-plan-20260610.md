# 🚀 MVP 범위 & 릴리즈 계획 (백엔드 기준)

## 1. 1차 오픈(MVP) 범위 — 기획서 기준

### 포함 ✅
- 회원: 이메일 가입/로그인 + 소셜(구글/카카오/애플), 전화번호 인증
- 파트너: 사업자 가입 → 운영자 승인 → 고택/객실/요금 관리
- 운영자: 파트너 승인, 상품 등록(고택→객실 단계별), 회원/정산/권한 관리
- 예약: 검색(지역/날짜/인원) → 예약 → **토스 결제** → 알림톡
- 마이페이지: 예약 관리, 취소/환불, 찜, 후기, 쿠폰함
- 정산: 파트너별 정산 리스트/예정금 (1차 수동 확정)

### 제외(기획서 명시) ❌
- 즐길거리 **추가 결제**(콘텐츠 노출만), 타 OTA(네이버/카카오) 실시간 연동, 자동 추천(1차 수동 지정), 환불 완전 자동화, 정산 자동 입금
